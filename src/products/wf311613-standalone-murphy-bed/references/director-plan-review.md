## Directing contract

- Retain every completed operation in the next shot. Hide future parts.
- Use the sequence `PART → TARGET → ALIGN → CONNECT → HARDWARE → TIGHTEN → VERIFY` rather than a reverse exploded view.
- Default camera progression is `medium-wide 3/4 → medium target view → connection close-up → axis-readable macro → pull-back`.
- When a connection is inside, behind, or on the opposite face, move the camera there. Do not make a part cross installed geometry for visibility.
- The first repeated fastener gets a complete readable installation. Later identical fasteners may be faster, but each must visibly enter, rotate where applicable, seat, and remain installed.
- Steps 3–6 obey the PDF warning: start every bolt before tightening any bolt.
- Steps 25–27 are a four-person hero/mechanism sequence. Step 30–31 begin only after the unnumbered page-28 positioning operation has placed the cabinet level, plumb, and against the wall.

### Canonical hardware animation recipes

- **Wood dowel (#6/#7):** empty hole → dowel enters → axis alignment → insert halfway → mating part approaches on the same axis → surfaces seat → hold.
- **Cam joint (#8 + bolt #3/#4/#5/#22):** show empty bolt and cross-bore holes → seat #8 in the cross-bore with its opening aimed at the bolt path → insert the specified bolt along the joint axis → multiple visible turns → cam/bolt pulls the joint closed → final seat → hold. For Steps 3–6, stop at “started” for all bolts, then make a second tightening pass.
- **Wood screw (#12/#13/#14/#16/#21/#23/#24):** empty pilot hole → screw enters → align → tip contact → rotate and translate for multiple visible turns → head seats → short final tightening → hold.
- **Bolt + washer/bushing + nut:** keep each item separate; bolt passes through both members → washer/bushing slides onto the shaft where shown → nut catches thread → nut rotates and translates → final seat → hold.
- **Bracket (#15/#20/#25):** show bare corner → bracket enters from clear space → both faces seat → holes align → first fastener fully shown → remaining fasteners visibly installed → pull back to show the held joint.
- **Pivot/bearing (#18/#19):** show both large assemblies → align pivot axes → bearing enters its receiver → retaining hardware installs → pull back → 10–15° controlled test rotation → return.
- **Gas piston (E2):** wide view identifies the cabinet and bed connection → macro first end → attach → move to second end → attach → pull back → small mechanism test → return.

## Conflict audit against the current code checkpoint

The existing code is preserved. These conflicts must be resolved only after plan approval:

1. `stepSpecs` is not PDF-authoritative. Step 1 omits A1/A3; Step 2 omits A2/A4; Steps 3–8 assign wrong or incomplete parts; Steps 11–17 substantially mis-map the bed-face and carrier-frame operations.
2. Step 7 currently treats only B4 panels as the top cap and Step 8 incorrectly introduces E4. The PDF requires B1×2, B2×2, B3, B4×2 in Step 7 and mounts that entire subassembly in Step 8.
3. Step 9/10 handedness and targets are unsafe: current names place D9 on “left” and D8 on “right,” while the PDF should be implemented using an explicit PDF-left/PDF-right interior coordinate convention. Current Step 9/10 also misuse D3 and omit E5/#24 in the actual action mapping.
4. Current D3/D6/D7 semantics conflict with the PDF. D3 is a folding-leg member; D6/D7 are its two bracket/foot pieces. The model currently uses D3 as cabinet links and D6/D7 as simplified leg/foot geometry.
5. Steps 12, 14, and 15 currently omit/misplace C6 panels, C3 blocks, C1/C2/C4/C5 rails. Current motion can produce the exact forbidden layer inversion/mesh crossing between face panels and support rails.
6. Step 16 currently installs later-step deck parts instead of building the separate C8×2/C9/D1 carrier frame. Step 17 currently adds B2/B3 instead of joining the two complete large bed subassemblies.
7. Step 20 is currently named and framed as “under-deck.” The PDF shows D2 as five mattress-support slats on the accessible mattress-facing side after the two bed subassemblies are joined.
8. Step 25 currently has no #18 hardware and is a generic group move. The PDF requires the four-person bearing-to-D8/D9 cradle hero sequence plus two #18 bolts and left/right pivot close-ups.
9. Steps 23–27 do not yet encode the exact two-stage piston story: bearings and first piston ends in Steps 23–24; bed/cabinet pivot mating in Step 25; second piston ends and #17 nuts in Steps 26–27.
10. Step 30/31 geometry currently provides one wall angle per side, while the PDF requires two #15 brackets per side plus four #14 cabinet screws and two #23 wall screws per step.
11. Except for the Step 1 prototype, `createDirectorShots` emits generic offsets and empty hardware actions. It does not yet implement real hole targets, installation axes, bracket/pivot/piston recipes, start-before-tighten behavior, or occlusion-safe camera cuts.
12. Current generic staging offsets can make parts fly through installed geometry. Every step needs the explicit staging and insertion directions in this plan.
13. Current `pdfPage: index + 9` metadata is wrong because several PDF pages contain two numbered steps and page 28 is an unnumbered positioning instruction.
14. The current video appends two Option 2 scenes after Step 31. Option 2 exists in the PDF, but it is outside this requested Steps 1–31 review scope and must not be part of the approved 31-step implementation unless separately authorized.
15. The product name currently says “Queen Daybed Wall Bed.” For this implementation and UI selector it should identify the PDF-defined **standalone Murphy Bed** and must not inherit any side bookshelf/storage identity from older products.
16. Several geometry dimensions are proportional reconstructions while evidence metadata marks broad groups as high confidence. Part IDs/order are high confidence; unprinted dimensions, hidden joinery, and hole coordinates must remain explicitly reconstructed/estimated.

No runtime, product geometry, scene, animation, or export code was changed while producing this review plan.
