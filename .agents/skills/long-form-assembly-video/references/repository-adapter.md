# Repository adapter
Read this when operating in this repository; other repositories must substitute their inspected conventions.

- Product packages: `src/products/<product-key>/product/`, `assembly/`, `director/`, with public `index.ts`. Inventory/typed equivalents belong to that isolated package; approved source references use `references/<product-key>/` and product-owned `references/`.
- `src/products/registry.ts` registers products. Managers are composition roots; generic engine modules under `src/engine/` must remain product-agnostic. Do not register a new product during process-only work.
- `scripts/validate-assembly.ts` resolves `PROJECT_ID` or `PRODUCT_ID`; explicitly select the intended product rather than relying on defaults. It reports dependencies/operations/errors/warnings. Product-owned validation/tools and tests supplement it; a proxy validator alone cannot certify actual-mesh fit or visual cleanliness.
- Tests: Vitest (`npm test`); `npm run typecheck`, `npm run lint`, `npm run build`. Follow AGENTS.md's relevant local Next documentation before application code edits. Documentation-only routing changes need skill/frontmatter/link/content validation, not a Next build. Runtime changes need relevant checks; record failures honestly.
- Render entrypoints: `scripts/render-video.ts`, `render-checkpoints.ts`; inspect actual options before invoking. Renderer uses absolute `renderFrame(frameIndex/fps)`. Engine export tests cover identity, profiles, native surfaces and frame manifests. Resumability/resource capability must be verified, not assumed from this playbook.
- Output: `output/<product-key>/` with isolated frames, reviews, screenshots and versioned final directories. Audio/provenance/QA remain alongside each revision. Choose fresh revision paths; do not delete or overwrite existing outputs. Generate File now retains version-2 checkpoints under output/export-jobs/render-<profile>-<identity>-<uuid>/ until explicit Delete. Legacy temp jobs have no invented resume identity. Read docs/resumable-export.md for current operational contracts.
- Existing README describes historical checkpoints and is not current source authority. Inspect selected package and recorded approvals rather than treating old duration/status prose as truth.
- Skill discovery: repository-local `.agents/skills/long-form-assembly-video/SKILL.md`, routed by root AGENTS.md. Invoke as `$long-form-assembly-video` when cataloged, or explicitly ask the agent to read this SKILL.md. An already-running session may need a new discovery pass/session; do not claim it was dynamically registered here.
